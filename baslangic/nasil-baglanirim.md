# Sunucuya bağlan

## Java Edition

1. Minecraft Java Edition'ı aç, **Çok Oyunculu > Sunucu Ekle** de.
2. Sunucu adresine şunu yaz: `oyna.zauncraft.com`
3. Kaydet ve katıl.

{% hint style="info" %}
Sunucu **Minecraft 26.3** üzerinde çalışır. Eski sürümlerle de girebilirsin (ViaVersion destekli, 1.8'e kadar),
ancak yeni eşyalar eski sürümde eksik ya da farklı görünebilir. En iyi deneyim için güncel sürümü kullan.
{% endhint %}

## Bedrock Edition (mobil, konsol, Windows)

Sunucu Bedrock oyuncuları da kabul eder (Geyser ile).

1. **Oyna > Sunucular > Sunucu Ekle** de.
2. Adres: `oyna.zauncraft.com`, port: **19132**.
3. Kaydet ve katıl.

{% hint style="warning" %}
Bedrock'ta bazı menüler farklı çalışabilir. Menülerde **sadece sol tık / dokunma** kullan, sağ tık gerektiren işlem yoktur.
{% endhint %}

## Sesli sohbet

ZaunCraft'ta yakınlık tabanlı sesli sohbet vardır (**Simple Voice Chat**).

- **Java:** Minecraft'ına [Simple Voice Chat modunu](https://modrinth.com/plugin/simple-voice-chat) kur
  (Fabric, NeoForge, Forge ya da Quilt). Mod kurulu olmadan sohbeti duyamazsın.
- **Bedrock:** Sesli sohbet şu an Bedrock için desteklenmez.
- Oyun içinde ayarlar için `/voicechat` komutunu kullan.
