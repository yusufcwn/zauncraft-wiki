# Meslekler

`/meslek` komutuyla (kısa yol `/jobs`) bir meslek seçersin; o mesleğe uygun işler yaptıkça **Bakiye** ve meslek tecrübesi
kazanırsın. Meslek seviyesi arttıkça kazancın ve günlük sınırın da artar.

## Meslekler

| Meslek | Ne yapar? |
|---|---|
| Madenci | Taş ve maden kazar |
| Çiftçi | Ekin yetiştirir, hayvan besler |
| Oduncu | Ağaç keser |
| Kazıcı | Toprak, kum, çakıl kazar |
| Avcı | Yaratık avlar |
| Balıkçı | Balık tutar |
| İnşaatçı | Blok yerleştirir |
| Zanaatkâr | Eşya üretir |
| Simyacı | İksir demler |
| Büyücü | Eşyalara büyü yapar |
| Kâşif | Yeni yerleri keşfeder |
| Silah ustası | Silah ve zırh üretir |

## Kurallar

- Aynı anda **en fazla 3 meslek** seçebilirsin.
- Her gün meslekten kazanabileceğin para **sınırlıdır**: **1000$** + toplam meslek seviyenin her puanı için **10$**
  (örnek: toplam seviyen 50 ise günlük sınır 1500$). Sınır her gün **04:00'te** sıfırlanır.
- **Oyuncu öldürmek** meslekten para kazandırmaz.
- Meslek **günlük görevleri** vardır; tamamlayınca küçük bir ödül verir.
- Seviye arttıkça aynı iş daha fazla kazandırır, ancak birden fazla mesleğin kazancı biraz düşer.

{% hint style="info" %}
Meslek ödülleri bilerek düşük tutulmuştur; asıl para ticaret, teslimat ve satışlardan gelir.
Meslek menüsü: `/meslek browse`. İstatistiklerin için `/meslek stats`.
{% endhint %}
