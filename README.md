# ZaunCraft Wiki

ZaunCraft'a hoş geldin! Burada sunucuya nasıl bağlanacağını, ekonomi sistemini, mesleklerini, ihale ve takas gibi
özellikleri ve komutları bulabilirsin.

{% hint style="info" %}
Bu rehber sürekli güncellenir. Bir şey eksik ya da yanlışsa Discord sunucumuzdan yetkililere yaz.
{% endhint %}

1. [Sunucuya bağlan](baslangic/nasil-baglanirim.md) (Java ve Bedrock)
2. [İlk adımlar](baslangic/ilk-adimlar.md): meslek seç, para kazan, evini kur

## Sunucu hakkında

ZaunCraft, **Towny'siz saf bir SMP sunucusudur**: araziler oyuncuların güvenine bağlıdır, PvP açıktır (lobi ve
özel arena hariç) ve ekonomi "zengin olmak kolay olmasın, sıkmasın" prensibiyle tasarlanmıştır.

| | |
|---|---|
| Oyun | Minecraft Java Edition (Bedrock destekli) |
| Ekonomi | Bakiye ($) ve ZaunCoin |
| Öne çıkanlar | Meslekler, ihale, sipariş, takas, teslimat, düello arenası, kasalar |
| Sesli sohbet | Simple Voice Chat |
| Topluluk | [Discord](topluluk/discord.md) |
